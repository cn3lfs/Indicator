# 简介

缠论可视化交易插件。在通达信里把缠师原文的 **分型 → 笔 → 线段 → 中枢 → 走势类型 → 三类买卖点**
精确画出，并叠加 **动力学（MACD 背驰）** 增强的信号质量与买卖点研判。所有定义、定理均贴近
《缠中说禅教你炒股票108课》原文，注释中标注课文编号可溯源。

# 功能介绍

插件保留旧编号函数兼容，同时推荐用 `Func30(mode)` 统一入口一步输出各类结果（示例见文末）。

## 形态学（几何）

- **分型 / 笔 / 线段**：对原始 K 线做包含处理后识别顶底分型，连成笔，再划分线段（第62-71课）。
- **中枢**：由连续三段走势的重叠区间构造中枢，记录重叠区间 `ZG/ZD` 与全幅极值 `GG/DD`（第17/18课）。
- **走势类型**：把相邻中枢归并为 盘整 / 上涨 / 下跌（第17课）。

## 买卖点（形态学 + 动力学）

- **三类买卖点**：第一类（趋势背驰）、第二类（一买后回抽）、第三类（中枢突破回试不破）（第20/21课）。
- **信号质量**：价格背驰之外再用 MACD 柱面积确认，区分 观察 / 确认 / 强质量（第24/27课）。

## 进阶研判（动力学）

- **中枢关系**：相邻中枢按中心定理二判为 上涨延续 / 下跌延续 / 中枢扩展（第20课）。
- **背驰-转折**：一类买卖点后首段反弹力度，区分 中枢扩展 / 更大盘整 / 反趋势（第29课）。
- **三买后续**：三类买卖点之后中枢 扩张 还是 新生（趋势）（第21课）。
- **背驰段**：标出构成背驰的那段走势，作为区间套精确入场的观察区间（第27课）。
- **区间套背驰段**：在线段级背驰段内部标出笔级一类背驰段，辅助逐级收缩转折范围（第27/61课）。

## 均线系统（第11-15课）

- **体位与吻**：短长均线的 女上位/男上位 体位，以及 飞吻/唇吻/湿吻 三类吻（反抗强度递增）。
- **均线趋势力度**：短长均线相交面积——这是第15课对「趋势力度/背驰」的原文原始定义（MACD 仅为第24课的辅助）。

目前仅支持通达信软件使用。**按你的通达信位数选择对应 DLL**（位数不匹配会加载失败）：

| 通达信版本 | 复制哪个文件 |

安装步骤：

1. 将对应的 DLL 复制到通达信安装目录下的 `T0002\dlls` 目录之中；
2. 在通达信「功能 → 公式系统 → 公式管理器」里把本 dll 加载到 **1 号 dll 插件**（公式中即用 `TDXDLL1(编号,...)` 调用）；

   `formulas/chan-debug.txt`；条件选股先导入核心三类和 standard/dynamics/small-turn/context/multi-buy，

发布产物统一放在 **`build/`** 目录。两个 DLL 均已**静态链接** MinGW 运行时（`libgcc`/`libstdc++`），自包含，

## 40 号 旁路注册真实收盘价 / 成交量

通达信 DLL 计算函数只有 3 个输入槽，已被 `H/L`（及配置/mode 码）占满，因此 MACD 背驰与均线默认用
`(H+L)/2` 作收盘价代理。40 号提供**旁路注册**绕过该限制：

```tdx
XC:=TDXDLL1(40,C,V,0);   { 注册真实收盘价 C 与成交量 V，输出透传 C 便于核对 }
```

把这一行**置于其它本插件函数之前**，之后中枢/买卖点/均线/背驰等会在内容校验通过时自动改用真实 C，
湿吻放量骗线过滤（30 号输出 13）也才有成交量可用。校验规则：注册的收盘价每根都须落在 `[L,H]` 内
（真实 OHLC 必然如此），否则视为错配（如跨股票/过期数据）而**回落到 `(H+L)/2` 代理**——故未注册或注册
错误均不会算错，只是退化为现状（零回归）。注意通达信按公式行序求值，40 号必须排在消费函数之前。

> 完整可导入公式在 `formulas/` 下维护；下面示例与 `formulas/chan-main.txt`、`formulas/chan-debug.txt`

## 示例四：无未来函数的当下买卖点（30 号输出 109 / 110）

5 号等常规买卖点是**用全部数据事后划出的结果**：最后一笔、最后一个中枢还会随新 K 线改变，
而且全量结果只留下事后“胜出”的信号——当下确实出现过、随后被新低/新高否定的一类点（背驰失败）
会被抹掉。直接拿它回测等于偷看未来（幸存者偏差）。

109/110 用**逐步重放**计算：在每个分型成立的那根 K 线上，只用截至当时的数据重算
笔 → 端点 → 中枢 → 买卖点，只认端点已被下一端点确认的信号，并记录信号的出现与失效：

- **109 当下确认信号**：信号在它**当下可知**的那根 K 线上出现（不是极值那根），值为 1/2/3 买、11/12/13 卖。
- **110 信号失效**：此前出现过的信号在该 K 线上被否定，值为被撤销的信号码。

```
{ 30 号扩展编码：mode = -(配置码*10000 + 输出*10)；配置码 0 即默认严格笔 }
当下信号:=TDXDLL1(30,H,L,-1090);
信号失效:=TDXDLL1(30,H,L,-1100);
DRAWTEXT(当下信号=1,L,'一买'),COLORRED;
DRAWTEXT(当下信号=2,L,'二买'),COLORRED;
DRAWTEXT(当下信号=3,L,'三买'),COLORRED;
DRAWTEXT(当下信号=11,H,'一卖'),COLORGREEN;
DRAWTEXT(当下信号=12,H,'二卖'),COLORGREEN;
DRAWTEXT(当下信号=13,H,'三卖'),COLORGREEN;
DRAWTEXT(信号失效>0,H,'失效'),COLORGRAY;
```

线段中枢用配置码 1100：`-11001090` / `-11001100`。每一步都与“只拿当时数据完整重算”逐时刻一致（有测试）。
全量重放的耗时约为 分型数×端点数：日线数千根约数百毫秒，结果缓存；分钟线等长序列可把第三输入
写成数组、第 1 项给正整数 N，只重放最近 N 根（窗口起点前的信号作为基线，不产生事件）。

## 标记含义说明

- **信号质量 `QLT`（10）**：`0` 观察、`1` 确认、`2` 强质量。`2` 表示候选买卖点除价格背驰外，
  还得到 MACD 柱面积缩小等动力学确认；完整第24/25/37课标准趋势背驰组合请看 30 号输出 20。
- **中枢关系 `EXT`（11）**：按第20课走势中枢中心定理二在后一个中枢起点标记 —— `2` 中枢扩展
  （前后中枢全幅区间重叠，形成高级别中枢，对应第29课最后中枢扩展、第21课三买后中枢扩张）、
  `1` 上涨延续、`-1` 下跌延续。
- **背驰-转折 `REV`（12）**：按第29课对每个第一类买卖点标注其后首段反弹力度 —— `1` 最后中枢扩展
  （最弱反弹）、`2` 更大级别盘整、`3` 反趋势（最强），`0` 表示非一类买卖点。
- **三买后续 `AFT`（13）**：按第21课对第三类买卖点标注后续 —— `1` 中枢扩张（与后续中枢形成更大
  级别中枢）、`2` 中枢新生（形成同向新中枢/趋势），`0` 表示后续中枢尚未形成。注：单级别图上后续
  中枢常与三买共享枢轴，正例较少，多级别/真实行情中更易出现。
- **背驰段 `BSG`（14）**：按第27课标记第一类买卖点「最后那段构成背驰的走势」—— 买点起点 `1`、
  终点 `2`，卖点起点 `-1`、终点 `-2`，连成线即背驰段，可作为区间套精确入场的观察区间。
- **小转大必要条件（30 号输出 14）**：按第44课标记小级别背驰引发大级别转折的必要条件 ——
  底背驰后的最后中枢三买标 `1`，顶背驰后的最后中枢三卖标 `-1`，`0` 表示尚未满足该必要条件。
  对应 `TDXDLL1(30,H,L,140)`。其关联小级别一类端点、三买/三卖首次离开/回试端点见
  30 号输出 42、30 号输出 38、30 号输出 39。
- **A-B-C 背驰结构（30 号输出 15）**：按第37课标记一类背驰的 c 段是否包含对最后中枢 B 的三买/三卖 ——
