# 简介

通达信缠论插件。按《缠中说禅教你炒股票108课》原文，把 **分型 → 笔 → 线段 → 中枢 → 走势类型 → 三类买卖点**
与 **动力学（MACD 背驰）** 画进通达信；所有定义在源码注释里标注课文编号可溯源，原文未定义处的取舍见
[`docs/chan-ambiguity-decisions.md`](docs/chan-ambiguity-decisions.md)。

> **2026-09 架构重写，接口不兼容**：旧的 1–20 号函数与 30 号 mode 编码已移除，旧公式需换用
> `formulas/` 下的新公式。新接口：函数号即输出，第三个参数传0–9999的小整数预设号。

# 设计要点

- **当下优先，无未来函数**：引擎按时间逐根推进，每个分型在其右侧首根非包含K线出现时定型；
  买卖点在它**当下可知**的那根K线上出现，此后若被新低/新高否定，在否定那根K线上给出“失效”。
  全量画出的历史买卖点只保留事后胜出者、隐藏当下失败的信号（幸存者偏差），不能用于回测。
- **两种口径分开给**：结构（笔、线段、中枢、走势类型）用当前全部数据画出，最后一段会随新K线改变；
  买卖点、失效、止损参考、背驰力度、吻、缺口、分型强弱都是当下口径。
- **分层与单一路径**：`core/` 为纯领域引擎（形态 → 结构 → 动力 → 买卖点），每层都是可续算的“流”，
  批量结果就是把全部数据喂完后的状态；`tdx/` 只负责把结果投影成逐根序列。
- **性能**：含逐根当下事件在内，10 万根K线全量分析约 60ms（笔级）/ 30ms（线段级）。

**预设号（api v20）**：`0` 默认笔级，`1` 默认线段级（共享同一次分析），`2` 主图口径（笔中枢服从所属特征序列线段、快速发布）。
每个预设都显式包含 `signals.publication`，5/41、6/42、7/43读取同一预设的同一事件流，编号不再暗中改发布策略。
自定义预设在 DLL 同目录的 UTF-8 `czsc-presets.ini`，节名 `[3]` 至 `[9999]`，也可覆盖内置0/1/2。
示例见 [formulas/czsc-presets.ini](formulas/czsc-presets.ini)；字段名与schema一致，枚举填写选项末段（如 `stroke.rule=4k`、`outputs.levels=segment`）。
通达信一个预设选择一个视图（stroke或segment）；C接口可同时选两级。中枢框内置为initial，C默认为extended。
未知/重复字段或依赖冲突拒绝该预设；未定义/非法预设所有输出为0。`46`号诊断：0合法、1编号非法、2不存在、3文件不可读、4预设字段非法。
INI在DLL首次使用时加载；改文件后重新加载DLL。旧十进制码只供历史迁移，不再接受；映射见下方CSV。

**真实收盘价**：三个输入已被 H、L、预设号占满，MACD 默认用 `(H+L)/2`。在公式里先写
`XC:=TDXDLL1(40,C,V,0);`（须在其它调用之前），之后的调用即改用真实收盘价与成交量；
注册的收盘价只有逐根落在 `[L,H]` 内才会被采用，错配数据自动回落。

# 安装

| 通达信版本 | 复制哪个文件 |
| --- | --- |
| 32 位（经典版） | `build/CZSC.dll` |
| 64 位（新版） | `build/CZSC64.dll` |

1. 把 DLL 复制到通达信安装目录 `T0002\dlls`；
2. 「功能 → 公式系统 → 公式管理器 → DLL 插件」把它绑定到 **1 号插件**（公式里即 `TDXDLL1`）；
3. 按 [`formulas/README.md`](formulas/README.md) 导入公式：主图 `chan-main`、选股 `chan-buy-select` /
   `chan-sell-select`。

两个 DLL 均静态链接 MinGW 运行时，仅依赖系统自带的 `KERNEL32.dll` / `msvcrt.dll`。

# 编译与测试

在 WSL2 中用 MinGW-w64 交叉编译（`sh scripts/bootstrap-wsl-mingw.sh` 安装工具链）：

```bash

make test      # 原生 g++ 运行单元测试与公式校验
```

测试分三类：原文规则单测、不变量性质测试（顶底交替、价位推进、每个前缀的因果性、增量=整条重算），
以及上证指数日线真实样本。

### 分析与显示口径

`stroke.rule=4k`：社区4K笔，原始极值下标差≥3，合并极值下标差≥3，两分型不共用K线，不要求额外独立合并K线；价位推进仍须满足。
`fractal`：社区分型笔，相邻顶底直接连接，仅须顶高于底，不作跨分型细化。`new`：合并差≥3且原始差≥4，亦为社区放宽。
`stroke.endpoint=extreme/first/bounded` 分别为同型极值延伸、次高次低、合并K线包络，互斥枚举取代旧十位与百万位。
`segment.method=feature` 按第67/71课；启发式为社区口径。1+1终结未开放：第71课有条件特例不能代替两种特征序列情况。
中枢扩张仍按第20课分析；是否显示高层中枢由输出与绘图选择，不能关闭判据而改信号定义。

`projection.segmentBoundary=first/last` 只改变线段端点行index/price；划分、StartBreak、有缺口极值检查始终按extremeIndex。
ZG/ZD、背驰区间、信号位置与失效价、事件及递归均用真实极值。笔级不受分界投影影响，启发式只能extreme。
`projection.centerBox=initial/extended` 只改变中枢框end为前三构件或最后成员真实极值；结构lastPivot、延伸、信号不变。
业务端点步长28字节，extremeIndex偏移24；历史论证见v4文档答复。

`center.strokeFormation=segment` 为社区笔中枢口径：按真实极值归属父线段，首笔反向、三笔及延伸不跨父段，上升段下上下，下降段上下上。
父段未定型则中枢保守未定型；范围截断不等于定理三破坏。线段中枢和高层递归保持按进入段（避免循环依赖）。
默认entry保留旧业务结果，改变该字段会改变笔级中枢、走势、背驰、信号及递归。出处与统计见v5答复；v20 key全局唯一，不再按place去重。

## 买卖点发布与止损

预设2显式使用`signals.publication=early`，真实端点分型确认即发布，不等下一反向笔；后续结构变化可撤销。
标准发布等待下一端点，C默认仍standard以保留旧字节。5/41、6/42、7/43读取预设同一发布策略，编号不暗中切换算法。
快速失效价为原买卖点顶底分型极值：买取low、卖取high，冻结于发布当时；标准三类失效价仍ZG/ZD。
标记写在当下可知K线上，不回填到历史极值。结构撤销不是自动成交止损；主图只显示买卖点与固定止损点，复盘副图已删除。
选股44/45按原(index,type)精确撤销最新可显示点，同类旧点失效不会误伤新点，窗口为最近三根。

### 包络端点（v6死锁修复）

`stroke.endpoint=bounded` 为社区合并K线包络：极值闭区间内不得高于顶或低于底，含端点，相等允许；舍弃影线不阻止成笔。
真实末端同型分型照常延伸，原始新高/新低仅作未确认延伸候选（fractalAt=-1），不能反向成笔或确认信号。
反向成笔复核跨度/价位及合并包络；延伸破坏尾部时先找已确认同型分型修正起点并检查两侧，失败则回退两笔，从较早端点接续。
链可回退，暂不承诺端点定型（confirmedAt=-1）。五种笔均适用，下游自然接受新笔及事件撤销。
该枚举与first互斥，不再用非法整数码表示冲突；publication独立进入分析身份。修复统计见v6末尾答复。

### 笔中缺口（api v20）

`stroke.gap`：`none` 默认不处理；`asbar` 每个同向原始K线缺口给合并/原始跨度各加1；`large` 包含计数，并在比例严格大于浮点 `gapThreshold`（默认0.02）时跳过跨度。
只查两端极值闭区间内的相邻原始K线，不查未来回补。向上比例为 `(L[i]-H[i-1])/H[i-1]`，向下为 `(L[i-1]-H[i])/L[i-1]`，分母须正，相等不算大缺口。
两个可选策略都是社区/非原文，仍要求分型成立、价位推进、czsc互含检查及包络约束；分型笔只能none。
INI写 `stroke.gap=large`、`stroke.gapThreshold=0.02`；不再使用千万位。细节与统计见 [v7答复](docs/nextjs-quant-adapter-v7.md)。
