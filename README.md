# 简介

通达信缠论插件。按《缠中说禅教你炒股票108课》原文，把 **分型 → 笔 → 线段 → 中枢 → 走势类型 → 三类买卖点**
与 **动力学（MACD 背驰）** 画进通达信；所有定义在源码注释里标注课文编号可溯源，原文未定义处的取舍见
[`docs/chan-ambiguity-decisions.md`](docs/chan-ambiguity-decisions.md)。

> **2026-09 架构重写，接口不兼容**：旧的 1–20 号函数与 30 号 mode 编码已移除，旧公式需换用
> `formulas/` 下的新公式。新接口：函数号即输出，第三个参数直接写配置码。

# 设计要点

- **当下优先，无未来函数**：引擎按时间逐根推进，每个分型在其右侧首根非包含K线出现时定型；
  买卖点在它**当下可知**的那根K线上出现，此后若被新低/新高否定，在否定那根K线上给出“失效”。
  全量画出的历史买卖点只保留事后胜出者、隐藏当下失败的信号（幸存者偏差），不能用于回测。
- **两种口径分开给**：结构（笔、线段、中枢、走势类型）用当前全部数据画出，最后一段会随新K线改变；
  买卖点、失效、止损参考、背驰力度、吻、缺口、分型强弱都是当下口径。
- **分层与单一路径**：`core/` 为纯领域引擎（形态 → 结构 → 动力 → 买卖点），每层都是可续算的“流”，
  批量结果就是把全部数据喂完后的状态；`tdx/` 只负责把结果投影成逐根序列。
- **性能**：含逐根当下事件在内，10 万根K线全量分析约 60ms（笔级）/ 30ms（线段级）。

# 导出函数

公式写法：`TDXDLL1(编号, H, L, 配置码)`。

| 编号 | 输出 | 取值 | 口径 | 课文 |
| --- | --- | --- | --- | --- |
| 1 | 端点 | 顶 `1` / 底 `-1`（配置决定笔或线段） | 当前结构 | 第62-71课 |
| 2 / 3 | 中枢上沿 ZG / 下沿 ZD | 仅最初三笔／三段范围内逐根给值，延伸计算不变 | 当前结构 | 第17/18/20课 |
| 4 | 相邻中枢关系 | 在后中枢起点：`1` 上涨 / `-1` 下跌 / `2` 扩展 | 当前结构 | 第20课中心定理二 |
| 5 | 买卖点 | 一二三买 `1/2/3`、一二三卖 `11/12/13`，写在当下可知那根 | 当下 | 第20/21/24/27课 |
| 6 | 信号失效 | 被否定信号的码，写在失效那根 | 当下 | 第27/61课 |
| 7 | 失效价（止损参考） | 与 5 同根：一/二买为信号点低点、三买为 ZG；卖点对称 | 当下 | 第20/21课 |
| 8 | 背驰力度 | 与 5 同根：c/b 同色 MACD 面积比 %，`<100` 为背驰 | 当下 | 第24/37课 |
| 9 | 走势类型 | 走势区间内逐根：`1` 上涨 / `-1` 下跌 / `0` 盘整 | 当前结构 | 第17课 |
| 10 | 均线吻（MA5/MA20） | `1` 飞吻 / `2` 唇吻 / `3` 湿吻 / `4` 放量湿吻 | 当下 | 第11/12课 |
| 11 | 缺口 | 向上 `1` / 向下 `-1` | 当下 | 第37课 |
| 12 | 分型强弱 | 写在分型成立那根：强顶 `2` / 顶 `1` / 底 `-1` / 强底 `-2` | 当下 | 第62/82课 |
| 13 | 事后买卖点 | 同 5 的码，但写在极值K线上，**含未来函数，只用于复盘** | 事后 | — |
| 41 / 42 / 43 | 快速候选 / 失效 / 失效价 | 分型确认且满足结构条件即提示，不等待下一反向笔；可失败，同一历史点不重复提示 | 当下，社区/非原文 | — |
| 44 / 45 | 近三根有效买 / 卖点 | 自身未结构撤销的最新信号码；按原位置+类型关联 | 当下 | — |
| 40 | 注册真实收盘价/成交量 | `TDXDLL1(40,C,V,0)`，输出原样返回 C | — | — |

**配置码**（十进制各位）：个位笔类型 `0` 严格笔 / `1` 新笔 / `2` czsc 笔（借鉴 waditu/czsc：合并K线跨度≥3 且两端
分型K线区间互不包含）；十位 `0` 严格收笔 / `1` 允许次高低点收笔；百位 `0` 笔中枢 / `1` 线段中枢；
个位 `3` 社区4K笔 / `4` 社区分型笔（定义见下）；
千位 `0` 启发式线段 / `1` 特征序列线段；万位 `0` 极值笔 / `1` 合并起始笔 / `2` 合并最后笔；十万位 `0` 按进入段 / `1` 服从所在线段；百万位 `0` 允许笔内超出（默认）/ `1` 合并K线不得超出端点（含端点，相等允许，社区口径）。百万位1与十位1组合非法。常用：`0` 笔级，`1100` 线段级（特征序列法）。非法配置码输出全 0。

**真实收盘价**：三个输入已被 H、L、配置码占满，MACD 默认用 `(H+L)/2`。在公式里先写
`XC:=TDXDLL1(40,C,V,0);`（须在其它调用之前），之后的调用即改用真实收盘价与成交量；
注册的收盘价只有逐根落在 `[L,H]` 内才会被采用，错配数据自动回落。

# 安装

| 通达信版本 | 复制哪个文件 |
| --- | --- |
| 32 位（经典版） | `build/CZSC.dll` |
| 64 位（新版） | `build/CZSC64.dll` |

1. 把 DLL 复制到通达信安装目录 `T0002\dlls`；
2. 「功能 → 公式系统 → 公式管理器 → DLL 插件」把它绑定到 **1 号插件**（公式里即 `TDXDLL1`）；
3. 按 [`formulas/README.md`](formulas/README.md) 导入公式：主图 `chan-main`、选股 `chan-buy-select` /
   `chan-sell-select`。

两个 DLL 均静态链接 MinGW 运行时，仅依赖系统自带的 `KERNEL32.dll` / `msvcrt.dll`。

# 编译与测试

在 WSL2 中用 MinGW-w64 交叉编译（`sh scripts/bootstrap-wsl-mingw.sh` 安装工具链）：

```bash
make release   # 构建 build/CZSC.dll 与 build/CZSC64.dll，并校验 PE 位数、导入表、时间戳
make test      # 原生 g++ 运行单元测试与公式校验
```

测试分三类：原文规则单测、不变量性质测试（顶底交替、价位推进、每个前缀的因果性、增量=整条重算），
以及上证指数日线真实样本。

# 风险警示

本软件仅旨在实现最贴近缠师原文所的线段、中枢概念的可视化结果，软件免费分享使用，没有任何限制。

市场有风险，使用者自行承担任何由本软件而导致的买卖交易后果，作者本人不承担因为使用本软件而导致的任何直接或间接后果。

结构化接口已升 **api v20（不兼容主版本）**。分析配置 `czsc_config`（32字节）与输出位集合、显示投影 `czsc_projection`（12字节）独立。
`czsc_config_default/validate/id/parse` 提供默认、中文原因、规范文本身份与解析；`czsc_config_fields/choices/rules` 提供字段、带说明选项与禁用依赖，key全局唯一，`original=0`为社区或工程口径。
`czsc_build(input, config, outputs)` 一次构建两级，`czsc_level_*` 访问时传 `level=0` 笔级或 `1` 线段级，区间套直接 `czsc_nested_rows`。
`czsc_set_projection` 仅改显示分界和中枢框，不改分析、事件、递归或身份。默认分析为严格笔/极值端点/不处理缺口/特征序列/进入段/标准发布；默认中枢框含延伸。
旧 `czsc_snapshot_build`、整数配置接口、`CZSC_FLAG_*`、单级取表与 `czsc_nested_build` 已删除。
一次性旧码映射见 [legacy-config-map.csv](docs/legacy-config-map.csv)，完整240行；业务行布局保持v10，默认两级分别保留旧0/1100字节。

个位新增 `3` 社区4K笔：原始极值K线含两端≥4根（下标差≥3），两分型不能共用K线（合并极值下标差≥3），无需独立合并K线；价位推进沿用原有规则。
`4` 社区分型笔：相邻顶底直接连接、无最小跨度，仅须顶高于底，不作跨分型端点细化。同型仍由十位选择极值延伸或保留首点。
现有 `1` 新笔也标为社区放宽（合并差≥3、原始差≥4）；第62/77课正文要求独立K线，不能将这些放宽口径标为原文。

千位2“1+1终结”未开放：第71课首笔破坏后的三笔终结是有条件特例，不能代替第67课两种特征序列情况；需求未给完整社区判据。
万位0/1/2仅在特征序列算法（千位1）下有效；启发式+非零万位非法，例如10000非法，11100/21100合法。中枢扩张按第20课计算；“不显示扩张/仅同级”是前端显示口径，可只画 `czsc_centers`、隐藏高层递归中枢。买卖点和事件仍按完整结构计算，不能关闭扩张判据而改变信号定义；同级中枢延伸照常保留。详见需求文档末尾答复。

万位1/2为社区/非原文显示口径（`original=0`）。线段划分、StartBreak、缺口确认仍按第67/71课极值判定；只改变端点行 `index/price` 及TDX 1号画线位置。
`extremeIndex` 为真实分析端点；笔级/万位0等于 `index`。端点 `fractalAt` 仍为真实极值分型成立时刻，`confirmedAt` 保证显示映射定型后不再变。
线段中枢ZG/ZD、背驰价差/速度/MACD区间、买卖点位置与失效价、事件和递归表均保持真实极值口径，不能用显示折线重算分析数据；信号index可不同于它引用的pivot行index。
API v9端点表步长仍28字节，调用方必须更新FFI定义；配置0/1100除size与追加字段外，所有v7业务字段保持逐字节不变。详见 `docs/nextjs-quant-adapter-v4.md` 答复。

十万位1是社区/非原文**分析口径**，只改变笔中枢：所属线段取同配置算法的真实分析端点，首笔必须反向、三笔和延伸均限于父段，上升段取下上下，下降段取上下上；[ZD,ZG]由首次合格三笔固定。
未定型父段可产生暂定中枢，父段两端和读取视界都稳定后才保守定型。父段范围截断不等于中枢定理三的破坏，不据此直接产生第三类买卖点。线段中枢及更高递归层保留进入段规则（方案ii，避免循环依赖）。
此选项会改变笔级中枢、走势、背驰、买卖点及递归结果，默认0保持不变；万位画线投影不参与归属。v9所有结构体布局与v8相同，新增 `place=100000` 的 `center.entry/center.segment` 均 `original=0`。
选项身份按 `(place,value)`；`center.segment` 在百位与十万位两个分组都有使用，不能仅按key去重。原文依据、边界及SSE差异统计见 `docs/nextjs-quant-adapter-v5.md` 答复。

## 快速买卖点提示

主图与选股采用41/42/43号。旧5/6/7号等待下一端点确认的事件语义保持不变；C快照api为v10（布局与v9一致），
配置0/1100及既有golden不变。快速口径只提前事件准入，不更改笔、中枢、背驰与三类点的结构判据。
候选在端点分型确认时可提示，后续端点延伸或结构变化可失效；42号失效依赖结构更新，
43号在提示时给出价格边界，并非自动成交止损。标记写在当时可知K线上，不回填到历史极值。
复盘副图已删除，13号旧接口仅保留兼容。

快速信号43号失效价统一采用买卖点端点分型的极值：一/二/三买取底分型最低价，
一/二/三卖取顶分型最高价。取的是原买卖点位置，不是提示当天K线，也不是中枢ZG/ZD；
提示发出后该价冻结。42号仍表示结构失效，价格止损需按43号边界执行。

### 主图方向中枢及失效关联

主图和选股的中枢/快速信号统一用101000：严格笔、特征序列父线段、十万位1。
上升父段排除进入笔，从向下笔起取下上下三笔；下降父段排除进入笔，从向上笔起取上下上三笔。
绘制范围只取这三笔的四个端点，不含进入笔或后续离开笔。线段方向与红色1100线段一致，
不从笔中枢进入段反推父段方向；原默认配置0仍供既有调用使用。
主图不显示结构失效文字，仅显示买卖点及固定分型极值止损点。选股改用44/45号按原买卖点身份过滤结构失效。
快速模式仅首次提示当前末端点，不把后来确立的父段中旧拐点补发为当下信号。

44号近三根内有效最新买点码，45号对应卖点码；同根先按41号优先级选出可显示信号。
结构撤销按原(index,type)精确移除，不按撤销当天或仅按买卖类型关联；
因此同类型旧买点失效不会误伤新买点，未显示过的同根低优先级点也不参与选股。
超过三根的信号退出选股窗口。42号原撤销码保留兼容，不再用“任意失效COUNT”决定选股。

### 百万位：笔内合并K线包络（api v10，死锁修复）

百万位0保持v9原路径；百万位1以包含处理后的合并K线H/L检查两端极值下标覆盖的闭区间，
不得高于顶、低于底，端点计入，相等允许。包含处理舍弃的原始影线不阻止成笔。
五种笔均适用；与十位1（次高次低收笔）组合非法。社区/非原文口径，metadata original=0，
选项键stroke.innerAllowed / stroke.innerBounded不变。

真实末端分型始终照常同型延伸。未确认的新高/新低作为延伸候选显示，fractalAt=-1，
只移动末端，不独立参与反向成笔、分型表或确认买卖点；随后真实分型确认时替换候选。
反向成笔须满足各自ValidStroke与合并包络；延伸破坏旧尾部包络时，先以已确认同型分型修正起点并检查左右合法性；修正不了再回退被破坏的两笔，
从较早端点接续，不冻结末端。该配置允许历史尾部回退，故暂不承诺不可回改的定型前缀，
C接口端点结构定型confirmedAt为-1。线段/中枢/买卖点/递归自然使用新笔，结构变化可撤销旧信号。

底层StrokeStream/BuildStrokeEnds/BuildPivots启用包络时须提供原始Series；
需逐K线显示未确认延伸时先调用StrokeInputs，Analyze已统一接入。
TDX快速模式作为独立缓存字段，不占百万位；配置0和1100及C结构体布局保持v9兼容。
详情与修复统计见docs/nextjs-quant-adapter-v6.md末尾答复。
