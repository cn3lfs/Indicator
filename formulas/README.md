# 公式包使用指南

| 文件 | 类型 | 内容 |
| --- | --- | --- |
| `chan-main.txt` | 主图叠加 | 笔（黄）、线段（红）、笔中枢上下沿、当下买卖点与失效标记 |
| `chan-buy-select.txt` | 条件选股 | 最近 3 根K线内当下确认了买点且未失效 |
| `chan-sell-select.txt` | 条件选股 | 最近 3 根K线内当下确认了卖点且未失效 |
| `chan-review.txt` | 副图 | 复盘：事后买卖点（含未来函数）、背驰力度、走势类型、分型强弱、缺口 |

主图与选股只用“当下”输出，信号出现后不会因后续K线而移动；复盘副图里的“事后买卖点”会随数据改变，
**不要用于回测或选股**。

## 导入步骤

1. 先按根目录 README 安装 DLL 并绑定到 **1 号 DLL 插件**；
2. 公式管理器 → 新建：主图选“技术指标公式 / 主图叠加”，选股选“条件选股公式”，复盘选“技术指标公式 / 副图”；
3. 把对应 `.txt` 全文粘贴进去，保存。

## 配置码

公式里 `TDXDLL1(编号,H,L,配置码)` 的最后一个参数：`0` 笔级（严格笔），`1100` 线段级（特征序列法），
`2` czsc 笔（更细，适合短周期）。换级别只需改这个数字。

## 边界

公式只消费 DLL 的结构、买卖点和动力学诊断。资金管理、同级别分解操作、仓位与交易执行（第16/31/38-41/89-90/103-108课）
需要账户与风险上下文，不在公式包内自动完成。
