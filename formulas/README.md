# 公式包使用指南

| 文件 | 类型 | 内容 |
| --- | --- | --- |
| `chan-main.txt` | 主图叠加 | 笔（黄）、线段（红）、笔中枢上下沿、当下买卖点与分型极值止损点 |
| `chan-buy-select.txt` | 条件选股 | 最近 3 根K线内出现了候选买点且未失效 |
| `chan-sell-select.txt` | 条件选股 | 最近 3 根K线内出现了候选卖点且未失效 |

主图使用41号快速买卖点，选股使用44/45号关联有效状态：端点分型确认且结构条件满足即提示，不等待下一反向笔完成。
42号给出后续结构失效，43号在提示当天输出失效价；候选允许失败，历史提示不回填、不移动。
同一极值K线、同一类型只提示一次，失效后不重新弹出历史点。失效事件依赖结构更新，不是逐笔成交止损；
价格触及失效价需自行处理。旧5/6/7号保留，供旧调用兼容。

## 导入步骤

1. 先按根目录 README 安装 DLL 并绑定到 **1 号 DLL 插件**；
2. 公式管理器 → 新建：主图选“技术指标公式 / 主图叠加”，选股选“条件选股公式”；
3. 把对应 `.txt` 全文粘贴进去，保存。

## 配置码

当前公式的中枢和快速信号使用 `101000`（严格笔、特征序列父段、按父段方向成枢）。
上升父段下上下，下降父段上下上；进入笔和离开笔不属于绘制的三笔构件。

公式里 `TDXDLL1(编号,H,L,配置码)` 的最后一个参数：`0` 笔级（严格笔），`1100` 线段级（特征序列法），
`2` czsc 笔（更细，适合短周期）。更换口径须同步中枢、信号、止损及有效状态调用的配置，避免显示与分析混用。

## 边界

公式只消费 DLL 的结构、买卖点和动力学诊断。资金管理、同级别分解操作、仓位与交易执行（第16/31/38-41/89-90/103-108课）
需要账户与风险上下文，不在公式包内自动完成。

快速信号43号失效价统一采用买卖点端点分型的极值：一/二/三买取底分型最低价，
一/二/三卖取顶分型最高价。取的是原买卖点位置，不是提示当天K线，也不是中枢ZG/ZD；
提示发出后该价冻结。42号仍表示结构失效，价格止损需按43号边界执行。

主图不显示“失效”文字，只保留买卖点及固定分型极值止损点；选股改用44/45号按原买卖点身份过滤结构撤销。

44号近三根内有效最新买点码，45号对应卖点码；同根先按41号优先级选出可显示信号。
结构撤销按原(index,type)精确移除，不按撤销当天或仅按买卖类型关联；
因此同类型旧买点失效不会误伤新买点，未显示过的同根低优先级点也不参与选股。
超过三根的信号退出选股窗口。42号原撤销码保留兼容，不再用“任意失效COUNT”决定选股。
