# 原文未定义处的实现口径（2026-09）

缠论原文（`chan-theory` skill）在若干边界上没有给出可执行的判据。第33课：多义性不是含糊性，
满足结合律的分解都合理——本项目对每个边界选定**一个**确定口径，写在这里与代码注释中，
避免同一数据在不同函数里被按不同口径解释。改口径须同步本表、注释与测试。

## 形态学

| 边界 | 原文 | 本实现取 | 位置 |
| --- | --- | --- | --- |
| 包含处理的初始方向（序列开头尚无上/下） | 第65课只定义了有前趋势时的方向 | 按高点差与低点差绝对值较大的一侧定向，等值取向上 | `ChooseDirection`（core/morphology.cpp） |
| 分型中的“最高/最低”遇等值 | 第62课“最高/最低” | 严格大于/小于才算分型（无包含K线下等值只会出现在包含合并后） | `DetectFractals` |
| 分型成立时刻 | 未定义 | 右侧首根非包含K线出现即成立（`confirmedAt`），此后并入的包含K线不改变分型 | `DetectFractals` |
| 笔的价位 | 第62课“底分型+上升K线+顶分型” | 向上笔的顶须高于起点底分型K线高点（向下对称）；czsc 笔另加两端分型K线区间互不包含 | `PriceProgress` / `Nested` |
| 特征序列有缺口时，分型极值被“等高”触及 | 第67课未定义 | 与分型极值持平不算再创新高/新低 | `FindSegmentEnd` |
| 线段起点在新段确立前被破 | 第71课“先破第一笔开始位置，旧线段延续” | 起点顺延到考察区间内最极端的同型端点再考察（特征序列法与启发式同口径） | `StartBreak` / `SegmentStream::RunHeuristic` |

## 刻意不做

- 缺口“是否回补”：需要未来K线，不输出（11 号只标出现）。
- 级别自适应的最小笔长：原文以显微镜倍数（第63课）定级别，笔长不随波动率变化；如需更细用 czsc 笔（配置个位 2）。
- 资金管理、仓位、止损执行：属操作策略（第16/38-41课等），不在 DLL 内；7 号只给信号的失效价。
